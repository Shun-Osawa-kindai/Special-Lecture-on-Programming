Debugging Lecture

The Blank Screen

恐怖の「真っ白な画面」

たくさんコードを書いたのに、キャンバスが真っ白のまま何も描画されない。そんな状況に出会うことはプログラミングの初期において日常茶飯事です。

パニックになる必要はありません。これはプログラムのどこかに「小さなエラー（バグ）」が潜んでいるサインにすぎません。

The Blank Screen

The Console

コンソールという「虫眼鏡」

真っ白な画面に直面したとき、私たちはブラウザの「コンソール (Console)」を開きます。

コンソールは、プログラムが裏側でどのようなエラーに直面しているのかを教えてくれる、開発者にとって不可欠な虫眼鏡です。

Reading Errors

エラーメッセージを読み解く

Uncaught ReferenceError: createcanvas is not defined

コンソールに表示されたこのエラー文を読み解いてみましょう。

ReferenceError 存在しない関数や変数名が呼び出されたときに発生します。
is not defined 「定義されていません（見つかりません）」という意味です。

Strictness

プログラムは融通が利かない

大文字・小文字の厳密さ

人間であれば「createcanvas」でも意味を察してくれますが、コンピュータは1文字でもスペルや大文字小文字が異なると、全く別の命令と認識してエラーを返します。

キャメルケースの法則

p5.jsの命令の多くは createCanvas のように2つ目の単語の頭が大文字になっています（キャメルケース）。

Source: Wikimedia Commons (CamelCase_new.svg)

Step 1 エラーを見つける
➔

➔
Step 3 コードを修正する

Types of Errors

よく出会う「2種類の虫」

構文エラー (Syntax Error)

書き方のルール違反です。タイプミス、閉じ忘れたカッコ、カンマの抜けなど、言語の文法そのものの間違いを指します。

引数エラー (Argument Error)

必要な情報（引数）の数が足りない、あるいは型が違うなど、関数や命令の使い方の間違いを指します。
