Dynamic Arrays

Dynamic Item Addition

固定長から「動的配列」への進化
「ユーザー入力を反映するワードクラウド」

これまで扱ってきた配列は、最初に要素数を固定した静的なリストでした。しかし実際のアプリケーションでは、ユーザーがキーボードで入力したデータをリアルタイムにリストへ追加（動的追加）する必要があります。

本講義では、配列の末尾に要素を拡張する push() メソッドと、配列の長さを動的に取得する length プロパティを組み合わせて、浮遊するワードクラウドを構築します。

The Push Method

Adding Items to Arrays

配列の末尾に要素を追加する push() メソッド

配列名に続けてドット（.）を打ち、push() メソッドを実行します。

  • 括弧の中に指定した値が、配列の常に一番最後（末尾）に追加されます。
  • 記述する順番（コードの上下関係）がそのまま配列内の格納順序に反映されます。
push() による動的追加
var wordCloud = [];
wordCloud.push("first");
wordCloud.push("second");

console.log(wordCloud);

Array Length Property

Dynamic Bounds

固定値を廃し wordCloud.length でループする

⚠️ 固定値ループの限界

for (var i = 0; i < 4; i++) のように固定値を使うと、ユーザーがいくら単語を追加しても最初の4つしか描画されません。

⭕ 配列の length プロパティ

wordCloud.length は、配列内に現在格納されている要素の総数を自動的に返します。

for (var i = 0; i < wordCloud.length; i++) { ... }

Synchronized Arrays

Parallel Arrays

単語と座標を同期させる 3つの配列

単語そのもの（wordCloud）に加え、画面上のランダムな出現位置を管理する wordsX と wordsY の空の配列を同時に用意します。

  • ユーザーがリターンキーを押したとき、3つの配列すべてに push() でデータを追加する
  • これにより、インデックス i を介して「単語」と「X・Y座標」が完全に同期します。
wordCloud.push(currentWord);
wordsX.push(random(width / 4, width * 0.75));
wordsY.push(random(height / 4, height * 0.75));

Floating Animation

Random Drift

毎フレーム微小に揺らぐ「ワードクラウドの漂流」

描画ループ（draw()）内の反復処理の中で、座標配列の各要素に小さなランダム値を加算更新します。

微小な移動の数式：
wordsX[i] += random(-1, 1);
wordsY[i] += random(-1, 1);

これにより、画面上の言葉たちが生き物のようにゆっくりと漂い続ける幻想的なクラウドが完成します。

for (var i = 0; i < wordCloud.length; i++) {
  text(wordCloud[i], wordsX[i], wordsY[i]);
  random(-1, 1);
  wordsY[i] += random(-1, 1);
}

Summary & Inspiration

動的配列がつなぐインタラクティブな表現

空の配列の用意、push() による動的追加、length プロパティによる動的な走査、そして複数配列の同期をマスターしました。

マスターのチェックリスト

  • 動的追加： array.push(item) で末尾に要素を拡張する
  • 動的長： array.length で要素数の変化に追従する
  • 並行配列： 複数の配列でインデックス i を共有して属性を管理する

文字サイズを変えたり、画面端でバウンドする物理演算を組み込んだりして、オリジナルワードクラウドに挑戦してください！
