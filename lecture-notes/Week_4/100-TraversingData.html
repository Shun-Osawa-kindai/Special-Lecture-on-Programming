199語のテキストデータをコンソールに一括出力する

カフカの『変身』の冒頭199語が格納された巨大な文字列配列 metamorphosis を例にします。

固定値の代わりにカウンタ変数 i を用いて metamorphosis[i] と指定することで、199回分の console.log() をたった数行のループで実現できます。

ループによる文字列配列の順次出力
for (var i = 0; i < 199; i++) {
  console.log(metamorphosis[i]);
}

Formatting Text Output

キャンバス上での文字列の整列と自動折り返し

① 文字幅に応じたカーソル進行（textWidth）

単語ごとに文字数が異なるため、textWidth() 関数を使って描画した直後の単語の長さを測り、cursorX を右へ進めます。また、単語同士がくっつかないよう + " " でスペースを挟みます。

② 画面端での改行処理（cursorY）

cursorX がキャンバスの width を超えたら、X座標を 0 に戻し、Y座標（cursorY）を一行分（例: 40px）下へ移動させます。

if (cursorX > width) {
  cursorX = 0;
  cursorY += 40;
}

Refactoring Code

Code Reduction

太陽系モデルをforループで65行から26行へ短縮

以前のスライドで手書きした8回分の重複描画コードを、for (var i = 0; i < 8; i++) によるループに置き換えます。

  • X座標：50 + i * 125
  • サイズ：sizes[i]
  • カラー：colours[i]
  • ラベル：names[i]

➔ コード量が劇的に減り、保守性が飛躍的に向上します！

for (var i = 0; i < 8; i++) {
  fill(colours[i]);
  ellipse(50 + i * 125, height / 2, sizes[i], sizes[i]);

  fill(255);
  text(names[i], 50 + i * 125, height / 2 + 150);
}

Array of Objects Architecture

Advanced Array Architecture

バラバラの配列を「オブジェクトの配列」へ統合する

パラレル配列（個別管理）の限界

sizes[i], names[i], colours[i] のように別々の配列で管理すると、要素の並び順がズレたときにバグの追跡が困難になります。

オブジェクトの配列（統合管理）

1つの惑星の属性（名前、サイズ、色）を1つのオブジェクトにまとめ、それを配列に格納します。

var planets = [
  { size: 8, name: "Mercury", color: "gray" },
  { size: 18, name: "Venus", color: "brown" }
];

Dot Notation & Scalability

Dot Notation & Extensibility

ドット記法による参照と、データの容易な拡張

ループ内では planets[i].size, planets[i].name, planets[i].color とドット記法で直感的にプロパティにアクセスできます。

データ構造（Data Structure）の拡張性：
科学の進歩やルールの変更で「冥王星（Pluto）」を再び追加したくなっても、配列の末尾にオブジェクトを1つ追加し、ループ条件を i < 9 に変えるだけで完結します！
for (var i = 0; i < planets.length; i++) {
  fill(planets[i].color);
  ellipse(50 + i * 125, height / 2, planets[i].size);
  text(planets[i].name, 50 + i * 125, height / 2 + 150);
}
