Index Modulation

インデックス変数 i と j でグリッドを彩る

二重ループのカウンタ変数（列カウンタ i や行カウンタ j）を、単なる座標計算だけでなく、図形のサイズやプロパティに直接代入してみましょう。

例えば、直径に 5 + i を与えると、左端の小さな図形から右側へ向かって徐々に大きく成長する美しいグラデーションパターンが生み出されます。

Distance Mathematics

距離場：中心からの距離に応じたサイズ変形

dist() 関数を用いて、グリッド上の各点と任意の中心点（あるいはマウス座標）との距離 d を計算します。

  • 中心からの距離が遠くなるほど d の値が大きくなる
  • その距離情報を描画半径やスケールに反映させる
var d = dist(
  width / 2, height / 2,  
);

Max Distance & Scaling

最大距離 maxDist によるスケール制御

対角線の最遠距離の算出

画面の中心から最も遠い隅（(0,0) など）までの距離を maxDist = dist(0, 0, width/2, height/2); としてあらかじめ計算します。

d / maxDist と割ることで、比率（0.0〜1.0の範囲）に正規化されたクリーンな係数を得られます。

正確なスケーリング

得られた比率に最大サイズ（例: 30）を掛け算することで、画面全体できれいに収まる制御された距離場アニメーションが実現します。

var r = (d / maxDist) * 30;

Modulo Mathematics

モジュロ演算子（%）による市松模様の構築

割り算の「余り」を計算するモジュロ演算子（i % 2）は、規則的なパターンを作る上で極めて強力です。

  • i % 2 == 0 ➔ 偶数番目の列（余りが0）
  • else ➔ 奇数番目の列（余りが発生）

これを利用して、白と紫のストライプや美しいチェッカーボード（市松模様）を描き分けられます。
