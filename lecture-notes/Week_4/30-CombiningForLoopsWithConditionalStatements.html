コンピュータ・アートの先駆者ヴェラ・モルナール（Vera Molnar）は、厳格な幾何学格子に「秩序の乱れ（ディスプレイスメント）」や「色彩の変化」を組み込む作風で知られます。

Color Segmentation

インデックス i で図形の色を切り替える

9個の四角形を並べるとき、全体のパレットを一色にするのではなく、i の範囲に応じて グレー ➔ パープル ➔ オレンジ ➔ モーブ（薄紫） と色相を切り替えます。

  • i <= 1（0, 1番目）：基調のグレー
  • i > 1（2番目以降）：ダークパープル
  • さらに条件を追加して多色グラデーションへ展開
i の値でストローク色を変更
for (var i = 0; i < 9; i++) {
  if (i > 1) {
    stroke(75, 0, 130); else {
    stroke(150);         rect(40 + i * 40, 80, 25, 25);
}

State Pollution

Drawing State Trap

画面全体が染まる「ステート持ち越し」の罠

⚠️ なぜ全図形がパープルになるのか？

else { stroke(150); } を書かずに if (i > 1) { stroke(purple); } だけを書くと、ループ終盤にパープルになった絵筆が、次のフレームの冒頭（i = 0）まで引き継がれてしまいます。

※p5.jsは明示的に色を戻さない限り、前回の最後の色で描き続けます。

💡 解決策：ループ直前または else でリセット

stroke(150);
for (var i = 0; i < 9; i++) { ... }

if (i > 1) { stroke(purple); }
else { stroke(150); }

Evaluation Order

Order Precedence Bug

else if の罠：条件は「大きい順」に書く

❌ 失敗例：小さい条件を先に書いた場合

if (i > 1) { stroke(purple); }
else if (i > 3) { stroke(orange); }
else if (i > 7) { stroke(mauve); }

i = 4 や 8 のとき、最初の i > 1 が先に true になって成立するため、後続の else if は一切テストされずスキップされます。

⭕ 正解：最も限定的な大値から降順に判定

if (i > 7) { stroke(mauve); }
else if (i > 3) { stroke(orange); }
else if (i > 1) { stroke(purple); }
else { stroke(gray); }

大きい値（7超、3超、1超...）から順に評価することで、各ゾーンが意図通りの色彩に染まります。

Controlled Displacement

変数 r で「揺らぎの激しさ」をゾーン別に制御

Jitter Formula

Coordinate Jitter

中心対称に揺らす：random(-r, r)

単に + random(r) と書くと、常に正方向（右・下）に偏ってズレてしまいます。

random(-r, r) と指定することで、元の基準位置を中心に前後・上下均等に散らばり、自然な「揺らぎ・崩れ」が表現できます。

r = 0 のときは random(0, 0) ➔ 0 となり、一切ブレずにピタリと静止します。
X・Y座標に揺らぎを合成
rect(
  40 + i * 40 + random(-r, r),  80 + random(-r, r),           25, 25
);

Row Duplication

Grid Expansion

複数行の配置とパラメータのバリエーション

完成した1行分の for ループ全体を複製（コピペ）し、基準となるY座標（例: 80 ➔ 160 ➔ 240...）を変えることで2行目、3行目を展開できます。

各行で条件分岐の境界値（i > 6, i > 4 など）や r の値を少しずつ変えることで、モルナールの版画のような豊かなテクスチャが立ち現れます。

for (var i = 0; i < 9; i++) {
  rect(40 + i * 40 + random(-r, r), 80 + random(-r, r), 25, 25);
}

for (var i = 0; i < 9; i++) {
  rect(40 + i * 40 + random(-r, r), 160 + random(-r, r), 25, 25);
}

Summary & Inspiration

Summary

アルゴリズムが織りなす「秩序と崩壊の美」

反復（for）に判断（if）と揺らぎ（random）を掛け合わせることで、冷たい計算機が有機的で詩的な芸術表現の道具へと変貌しました。

マスターのポイント

  • ステートリセット： 描画ループ前に基本色を設定し持ち越し事故を防ぐ
  • 判定順序の鉄則： else if は必ず「大きい閾値」から降順に書く
  • 中心対称の乱数： random(-r, r) で偏りのない自然な揺らぎを作る
  • パラメータの探求： 閾値や色相を変えて、自分だけの作品へ昇華させよう
