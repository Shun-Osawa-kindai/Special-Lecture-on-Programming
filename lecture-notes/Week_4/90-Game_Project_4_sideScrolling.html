Expanding the Game World

サイドスクロールの実装
「広大な世界を旅する錯覚の構築」

これまでの画面は1枚のキャンバス幅（例: 800〜1024px）に制限されており、キャラクターが端へ行くと画面外に出てしまっていました。

本ステージでは、キャラクターが一定位置に達すると静止し、代わりに背景全体が逆方向に動くことで、プレイヤーが長大なステージを前進している錯覚（サイドスクロール効果）を生み出します。

まずは「正面向き」のキャラクター描画コードを配置し、左右キーで動く土台から始めましょう。

Array Traversal: Trees

Multiple Objects with Arrays

背景の「木」を配列とforループで一括描画する

ステージ全体に多数の木を配置するため、X座標を格納する数値配列 trees_x を用意します。

  • setup() で trees_x = [100, 300, 500, 1000]; と初期化
  • draw() 内で for (var i = 0; i < trees_x.length; i++) で反復
  • Part 2Bの描画コード内の treePos_x をすべて trees_x[i] に置き換える
trees_x 配列の巡回と描画
// setup() 内
trees_x = [100, 300, 500, 1000];

for (var i = 0; i < trees_x.length; i++) {
  fill(120, 80, 40);
  rect(trees_x[i], treePos_y, 30, 150);
  fill(0, 155, 0);
  triangle(trees_x[i] - 50, treePos_y + 50, ...);
}

Array of Objects: Clouds

Objects inside Arrays

オブジェクト配列による「雲」の管理

「雲」はX座標だけでなくY座標（高さ）も個別に変えたいため、オブジェクトを要素に持つ配列にします。

  • clouds = [{pos_x: 200, pos_y: 100}, {pos_x: 600, pos_y: 80}, ...];
  • 反復条件は i < clouds.length（要素数分自動で回る）
  • 描画コードでは clouds[i].pos_x, clouds[i].pos_y と参照
clouds = [
  { pos_x: 200, pos_y: 100 },
  { pos_x: 600, pos_y: 80 },
  { pos_x: 900, pos_y: 120 }
];

for (var i = 0; i < clouds.length; i++) {
  fill(255);
  ellipse(clouds[i].pos_x, clouds[i].pos_y, 80, 50);
}

Coordinate Translation

The translate() Function

座標の原点を動かす：translate(x, y)

「絵筆を置く基準位置」そのものをスライドする

translate(500, 0) を呼ぶと、キャンバスの原点 (0, 0) が右へ 500px 移動します。

以降に描くすべての図形は、自分たちの座標値を変えることなく、一斉に右へ 500px ズレて描画されます。

⚠️ 意図しない軸ズレの注意点

translate(500, 300) のようにY軸まで動かすと、地面や雲まで沈み込んでしまいます。

水平スクロールでは、Y方向は必ず 0（固定）にして、X軸方向のみをシフトさせます。

translate(scrollPos, 0);

Scrolling Paradox

Dynamic scrollPos

キャラクターまで流れてしまう「連動の罠」

スケッチにあらかじめ用意されている変数 scrollPos を使って、translate(scrollPos, 0) を実行します。

直面する重大な問題：
そのまま実行すると、背景オブジェクトだけでなく操作しているキャラクターまで一緒に画面端へ流れて消えてしまいます。

私たちが作りたいのは、「キャラクターは画面内に留まり、背景だけが後方へ滑っていく」視覚効果です。

Isolation: push & pop

Matrix State Isolation

座標系を閉じ込める：push() と pop()

① push()：現在の座標状態を「記憶」

背景を描く直前に push(); を呼びます。「現在の画面原点（シフトしていない通常状態）」をメモリに保存します。

② pop()：記憶した座標状態に「復元」

背景を描き終えた直後に pop(); を呼びます。シフトされた座標系を破棄し、元の原点へ一瞬で戻します。

➔ その直後に描くキャラクターは、スクロールの影響を一切受けずに定位置へ描かれます！
