「for ループ（for loop）」の世界

ゲームの世界には、無数の木々、夜空にきらめく星、大量のコインなど、似たようなオブジェクトが何十・何百と並んでいます。

人間が100回同じコードをコピペするのは退屈で非効率ですが、「同じ作業を忠実に繰り返すこと」こそコンピュータが最も得意とする領域です。その司令塔となるのが for ループです。

Loop Anatomy

forループを構成する3つの要素

丸カッコ () の中が2つのセミコロン（;）で3分割されます。

  • 1. 初期化 (Initialization)： ループ開始前に1回だけ実行（例: var i = 0）
  • 2. 継続条件 (Condition)： この条件が true の間だけループが続く（例: i < 10）
  • 3. 後処理 (Afterthought)： 1回の処理が終わるたびに実行（例: i++）
forループの基本構文
for (
  var i = 0;      i < 10;       i++          
}

First Experiment

Loop Counter

カウンタ変数 i の推移と実行回数

💡 なぜちょうど10回動くのか？

カウンタ i は 0 から始まり、1, 2, 3, ... 9 と増えていきます。

i = 0 ➔ 1回目
i = 1 ➔ 2回目
...
i = 9 ➔ 10回目
i = 10 ➔ 条件 (10 < 10) が偽になり終了！

💻 コンソールでのテスト

function setup() {
  for (var i = 0; i < 10; i++) {
    console.log("Hello world");
  }
}

※ブラウザのコンソールには「(10) Hello world」とまとめられて出力されます。

Shape Drawing

Random Dispersion

図形を描く：重なり問題と random()

ループ内で ellipse(100, 100, 40, 40) と書くと、10個の円が全く同じ位置にぴったり重なり、1個にしか見えません。

座標に random(0, 800) を与えることで、10回ごとに異なるランダムな位置に散らばり、10個描かれていることが目で確認できます。

位置をランダムにして散開
for (var i = 0; i < 10; i++) {
  ellipse(
    random(0, 800),  random(0, 800),  50, 50
  );
}

Scaling Density

Mass Generation

10個から100個へ：数の拡大と色彩の制御

条件式の数値を 10 から 100 に書き換えるだけで、一瞬にして100個のオブジェクトが生成されます。

さらに fill(random(0, 255)) をループ内に入れれば、100個それぞれが異なるグレースケールの濃淡を持つ豊かな粒子模様を作り出せます。

Execution Context

Setup vs. Draw

setup() と draw() での違い

① setup() 内の for ループ

スケッチ起動時に1回だけ100個の円を描画して終了します。結果として静止した1枚の絵が残ります。

② draw() 内の for ループ（二重反復）

draw() 自体が毎秒約60回リピートします。その中で100回のループが回るため、毎フレーム新しい乱数で100個の円が激しく再描画され、アニメーション（ノイズ状の躍動）が生まれます。

Interactive Control

Variable Boundaries

mouseX でループの回数をコントロール

ループの継続条件に固定数値（100）ではなく、システム変数 mouseX を代入してみましょう。

マウスを左端に置くと円はわずか数個になり、右へスライドするにつれて密度がグングン増えていきます。ユーザー入力と反復構造のインタラクティブな融合です。

マウス連動のループ
function draw() {
  background(255);

  for (var i = 0; i < mouseX; i++) {
    ellipse(random(0, width), random(0, height), 20, 20);
  }
}

Summary

反復構造を武器に、豊かな表現へ

最初は記法が複雑に感じられますが、指が覚えるまで打ち込むことで自然と直感的に使いこなせるようになります。

for ループのマスターチェック

  • 3つのセクション：(初期化; 継続条件; 後処理)
  • インクリメントの短縮形：i++ は i += 1 と同じ
  • 波カッコ {} は必ずペアで閉じる
  • random() や mouseX と組み合わせて表現力を拡張
