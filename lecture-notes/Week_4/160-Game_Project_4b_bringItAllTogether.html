Function Fundamentals

Function Basics

独自関数の作り方と使い方
「定義 → 呼び出し → 引数受け渡し」

独自関数を使うと、処理を整理して再利用可能にできます。まずは最小パターンを確認しましょう。

  • 作る（定義）： function 関数名(仮引数) { ... }
  • 使う（呼び出し）： 必要な場所で 関数名(実引数);
  • 整理の効果： draw() は「司令塔」、関数側は「専門作業」に集中できる
対応関係の要点：
呼び出し側の collectables[i]（実引数）が、関数定義側の t_collectable（仮引数）に入ります。
最小パターン（この後ずっと使う形）
// ① 定義：1個分を処理する関数を作る
function drawCollectable(t_collectable) {
  ellipse(t_collectable.x_pos, t_collectable.y_pos, t_collectable.size);
}

// ② 呼び出し：draw() のループから1個ずつ渡す
for (var i = 0; i < collectables.length; i++) {
  if (collectables[i].isFound == false) {
    drawCollectable(collectables[i]);
  }
}

Architectural Benefits

Separation of Concerns

「反復」と「個別描画」の責務分離（SoC）

❌ 以前の構造（密結合）

描画関数の中に配列のループ、インデックス [i]、接触判定がすべて混ざり合い、コードを変更するたびに全体が壊れるリスクがありました。

⭕ リファクタリング後の構造（疎結合）

  • draw() の責務： リスト全体を巡回し、誰に何をさせるかを指示する（司令塔）
  • drawCollectable(t) の責務： 渡された1個を美しく描くことだけに専念する（描画専門）
  • checkCollectable(t) の責務： 渡された1個との距離を測り判定することだけに専念する（判定専門）
