Square Bracket Notation

配列を宣言する：
「角括弧 [ ]（Square Brackets）」の世界

配列を宣言するフォーマットは、通常の変数宣言と非常によく似ています。var キーワードに続けて変数名を書き、代入演算子 = を置きます。

ここで登場する新しい武器が「角括弧 [ ]」です。リストに含めたい値を角括弧の中に並べ、値同士をカンマ（,）で区切って記述します。

数値配列の宣言と初期化
var myArray = [1, 2, 3, 4, 5, 6, 7, 8];

Diverse Types & Empty Array

Data Type Variations

文字列配列・混在型・そして「空の配列」

① 文字列の配列と型の混在

文字列の配列も全く同じ記法で作成できます。各要素をシングルまたはダブルクォーテーションで囲みます。

var names = ["Alice", "Bob", "Charlie"];
var mixed = [42, "Hello", true];

⚠️ 異なるデータ型を混ぜるとプログラムが混乱しバグの原因になるため、原則として同種の型を並べます。

② 空の配列（Empty Array）の重要性

値を何も入れずに角括弧だけを書くと、空の配列が作られます。

var emptyList = [];

「最初から値が分かっている」場合よりも、プログラムの実行中（ユーザーのクリックやループ）に後から動的にデータを詰め込むための空の器として頻繁に使用されます。

Reading Elements

要素を取り出す：配列名[インデックス]

配列の中に入っている特定の値を取り出すときも、再び角括弧 [ ] を使います。

配列の名前の後ろに角括弧を置き、その中に取り出したい部屋のインデックス番号を書き込みます。

  • myArray[0] ➔ 1番目の要素を取り出す（値: 1）
  • myArray[5] ➔ 6番目の要素を取り出す（値: 6）
要素のコンソール出力

Modifying Values

配列の値を書き換える（要素の更新）

配列の特定の要素を別の新しい値に上書き更新したい場合も、通常の変数への再代入と全く同じ感覚で行えます。

左辺に myArray[5] のように対象の部屋を指定し、代入演算子 = で新しい値を流し込みます。

ほかの要素（0〜4番目や6番目以降）には一切影響を与えず、指定したピンポイントの部屋だけを綺麗に書き換えることができます。

Out of Bounds Trap

Out of Bounds

存在しない部屋を開けると何が起きるか？

⚠️ 魔の返り値：undefined（未定義）

要素が8個しかない配列（インデックス 0〜7）に対して、myArray[8] や myArray[100] のように範囲外へアクセスすると、JavaScriptは undefined を返します。

var myArray = [1, 2, 3, 4, 5, 6, 7, 8];
console.log(myArray[8]);  // => undefined
console.log(myArray[100]); // => undefined

💡 なぜサイレントバグになるのか？

他のプログラミング言語（JavaやC++など）では、範囲外アクセスをすると即座にプログラムがクラッシュして停止します。

しかしJavaScriptはエラーを出さずに静かに undefined を代入して処理を続けてしまうため、座標計算で NaN になったり、画面から図形が消える原因になります！
