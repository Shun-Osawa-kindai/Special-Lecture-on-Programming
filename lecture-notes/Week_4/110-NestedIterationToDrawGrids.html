Nested Iteration

Row to Grid Expansion

行から「二次元グリッド」へ
「二重forループ（Nested For Loops）」の威力

これまで単一の for ループを使って1行の図形列を描いてきました。しかし、同じ行を縦に何本もコピー＆ペーストするのは非効率です。

ループの中に別のループを配置する「ネスト（入れ子）」構造を使うことで、1次元の「行（Row）」を2次元の「格子状グリッド（Grid）」へと一瞬で拡張できます。

From Copy-Paste to Nesting

手動コピーの限界と、ネスト構造への昇華

❌ 手動コピー＆ペーストの悪夢

3行の行を作るために、同じ for ループを3回コピーし、Y座標の数値（30, 60, 90）を手動で書き換えるアプローチです。

行数が10行や100行に増えたとき、管理が完全に破綻します。

⭕ 二重forループによる自動化

外側のループで「行（Y方向）」を管理し、内側のループで「列（X方向）」を管理します。

たった数行のコードを書くだけで、無限の行数と列数を自在にコントロールできるようになります。

Execution Flow

Loop Within a Loop

外側ループと内側ループの実行メカニズム

二重forループでは、外側のカウンタ（例: h）が1歩進むたびに、内側のカウンタ（例: i）が最後まで（0から9まで）全速力で1周します。

  • 外側 h = 0 のとき： 内側 i が 0〜9 まで10回回り、1行目が完成。
  • 外側 h = 1 のとき： 内側 i が再び 0〜9 まで10回回り、2行目が完成。
for (var h = 0; h < 3; h++) {       for (var i = 0; i < 10; i++) {   ellipse(
      30 + i * 30,             30 + h * 30,             20, 20
    );
  }
}

Interactive Grid

Mouse Control

mouseX と mouseY でグリッド密度を操る

マウス座標による動的スケール

継続条件の固定値（例: 3 や 10）の代わりに、mouseY / 60 や mouseX / 60 を代入します。

マウスを動かすだけで、行数や列数がリアルタイムに増減するダイナミックなグリッドアートが完成します。

⚠️ ピクセル値のスケール調整

mouseX は数千ピクセルに達するため、そのままループ回数に使うとブラウザが重くなります。

➔ 適切な間隔幅（例: 60）で割り算（スケーリング）してから利用するのが作法です。

Debugging & Tracing

Tracing Execution

デバッグとコンソールによるループ追跡

二重ループの動きが直感的に分からないときは、図形の近くに h と i の数値をテキストとして描画してみましょう。

また、Chromeの開発者ツールにある「Sources（ソース）」タブのブレークポイント（Breakpoint）機能を使うと、プログラムを1行ずつ止めて変数の推移を完全に見通すことができます。

fill(255);
text("h=" + h + ", i=" + i, 30 + i * 50, 30 + h * 50);

Summary & Next Horizons

Summary

二重ループで広がる表現のフロンティア

外側と内側のカウンタ（h と i）を組み合わせることで、単純な1行の繰り返しから複雑な2次元マトリクス、タイルパターン、ゲームマップの描画まで自由自在に操れるようになりました。

マスターのチェックリスト

  • ネスト構造： 外側ループの1歩につき、内側ループが1周完了する
  • 座標の割り当て： X座標には内側カウンタ i、Y座標には外側カウンタ h
  • デバッグ手法： ブラウザの Sources タブでブレークポイントを活用する

ぜひエディタを開いて、サイズや色、ランダム性を組み込んだオリジナルのグリッドアートに挑戦してください！
