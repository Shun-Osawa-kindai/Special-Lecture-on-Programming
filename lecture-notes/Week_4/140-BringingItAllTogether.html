配列と数学関数を統合した
「星空のワープアニメーション（Star Field）」

これまで学習してきた「動的配列」「forループ」「距離計算（dist）」「乱数（random）」のすべてを結集し、宇宙空間を光速で突き進むような3Dパースペクティブ錯覚を2D画面上に再現します。

1,000個の星それぞれの位置と運動方向を並行配列で管理し、数学的な距離制御によって奥行きと加速を創出します。

Setup & Arrays

1,000個の空の器に乱数座標を詰める

星の総数を定数 numStars = 1000 として設定し、X座標とY座標を保持する2つの空配列を用意します。

  • setup() 内の for ループで 1,000 回反復
  • starPositionsX.push(random(0, width))
  • starPositionsY.push(random(0, height))
setup() 内での大量要素追加
var starPositionsX = [];
var starPositionsY = [];
var numStars = 1000;

for (var i = 0; i < numStars; i++) {
  starPositionsX.push(random(0, width));
  starPositionsY.push(random(0, height));
}

Distance Modulation

中心距離 d による星のサイズ制御

3Dパースペクティブの数学的再現

画面中央にある星は「遠く」にあるため小さく、外側へ広がるほど「近く」を通過するため大きく見せる必要があります。

dist(width/2, height/2, x, y) で画面中央からの距離 d を求め、サイズ r に反映します。

除算によるスケール調整

距離 d をそのまま半径に使うと画面が巨大な円で埋め尽くされてしまいます。

var d = dist(width/2, height/2, starPositionsX[i], starPositionsY[i]);
var r = d / 25;  ellipse(starPositionsX[i], starPositionsY[i], r, r);

Direction Vectors

Movement Arrays

各星の移動方向を定める 2つの方向配列

星ごとに固有の移動ベクトルを与えるため、starDirectionsX と starDirectionsY の配列を追加します。

  • random(-1, 1) でプラス・マイナスのランダムな数値を格納
  • -1 ➔ 左（または上）方向への移動
  • +1 ➔ 右（または下）方向への移動
  • 毎フレーム starPositionsX[i] += starDirectionsX[i] で座標を更新
push(random(-1, 1));
starDirectionsY.push(random(-1, 1));

Geometric Cleverness

全天体を「中央一点」から発進させる発想の転換

画面全体に散らばった星にランダムな方向を与えると、単なるブラウン運動（乱雑な揺らぎ）に見えてしまいます。

「森の中心」のメタファー：
森のど真ん中に立っているとき、どの方向へ歩き出しても必ず「森の外側」へと向かいます。

➔ 初期座標をすべて (width/2, height/2) に固定するだけで、あらゆるランダムベクトルが自然と「外側への放射」へと化けます！

for (var i = 0; i < numStars; i++) {
  starPositionsX.push(width / 2);
  starPositionsY.push(height / 2);
  push(random(-1, 1));
  starDirectionsY.push(random(-1, 1));
}

Speed Modulation

Perspective Acceleration

遠くは遅く、近くは速く：maxDist による速度制御

最大対角距離の事前計算

画面中央から隅 (0,0) までの最長距離を maxDist = dist(0, 0, width/2, height/2); として算出します。

d / maxDist と割ることで、中心（0.0）から外端（1.0）への滑らかな正規化スケールを作ります。

初動オフセットと速度の乗算

中心点では d = 0 のため、そのままでは静止してしまいます。微小値 0.1 を足して初動を与えます。

var speed = (d / maxDist) * 2 + 0.1;
starPositionsX[i] += starDirectionsX[i] * speed;
starPositionsY[i] += starDirectionsY[i] * speed;

Recycling Elements

画面端に消えた星を「中央へリセット」する

星が画面外へ突き抜けると、やがて宇宙空間は空っぽになってしまいます。

距離 d が最大距離 maxDist を超えた瞬間に、その星の座標を再び (width/2, height/2) に巻き戻します。

これにより、1,000個の要素が永遠に循環し続け、途切れることのない無限の宇宙旅行が完成します。
