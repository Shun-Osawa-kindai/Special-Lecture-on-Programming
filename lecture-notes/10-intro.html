Philosophy

Programming Philosophy

「車輪の再発明」をしない

一見、人が作ったものを組み合わせることは「かっこよくない」と感じるかもしれません。

しかし、実は逆です。

プログラマーの世界では「車輪の再発明」という言葉があります。
偉大な人が作ったものを、わざわざもう一度自分で発明する必要はない。 ライブラリを「組み合わせる」ことこそが、プログラマーの美学です。

Definition

Definition

「ハック」とは？

プログラマーが「ハック」と言うとき、

Learning Value

これは探索的なプロセスです。

プログラムを壊せるかどうか試してみて、そのあとで、また動くようにできるかを試すこともあるでしょう。

Special Lecture on Programming Slide 27 / 31
Hack Technique 01

Hack Technique 01

数値を極端に変える

引数（カッコ内の数字）を大きく変えてみましょう。何が変わったかを観察することで、役割が分かります。

p5.js Syntax
triangle(18, 100, 50, ...);
⬇️
p5.js Syntax
triangle(200, 100, 50, ...); // 横にずれた！

※もし壊れても、Undo (Command + Z) でいつでも戻せます。

Special Lecture on Programming Slide 28 / 31
Hack Technique 02

Hack Technique 02

コメントアウトで「消す」

行の先頭に スラッシュを2つ // 入れます。コードがグレーになり、実行されなくなります。

// rect(50, 50, 100, 100);
ellipse(200, 200, 50, 50);
「この行を消すとどの図形が消えるかな？」
→ 図形とコードの対応関係が瞬時にわかります。
Special Lecture on Programming Slide 29 / 31
Hack Technique 03

Hack Technique 03

コピーして増やす

上手く動いているコードをコピーして、
数値を少しずつ変えながら並べてみましょう。

ハックのサイクル：

  1. ellipse をコピーしてもう1行作る
  2. 3つ目、4つ目の数値を大きくして「幅」と「高さ」の変化を見る
  3. 複数の図形を配置して、画面内のレイアウトを調整する
