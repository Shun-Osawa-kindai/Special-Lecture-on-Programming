Shape Variety

四角形から、様々な形の世界へ

これまでは長方形（rect）を主に扱ってきました。
本講義では、円・楕円、直線、三角形、そして点といった多彩な幾何学図形の描き方をマスターします。

  • ellipse() : 楕円・正円の描画
  • line() : 2点を結ぶ直線の描画
  • triangle() : 3つの頂点を持つ三角形
  • point() : 1ピクセルの点と太さ制御

Ellipse Command

楕円・正円を描く：ellipse()

ellipse(x, y, width, height) は4つの引数を受け取ります。

  • (x, y) : 長方形の「左上」ではなく、図形の中心座標になります。
  • width, height : 横の直径と縦の直径（高さ）。同じ数値を指定すると正円になります。
// 中心(200, 200)、直径80の正円
ellipse(200, 200, 80, 80);

ellipse(200, 100, 150, 60);

Line Command

直線を描く：line()

line(x1, y1, x2, y2) は2つの端点の座標を指定します。

  • (x1, y1) : 始点の座標
  • (x2, y2) : 終点の座標
  • X座標を揃えれば垂直線、Y座標を揃えれば水平線になります。
line(50, 200, 350, 200);

line(200, 50, 200, 350);

挿絵：始点と終点を結ぶ line(x1, y1, x2, y2)

Triangle Command

三角形を描く：triangle()

triangle(x1, y1, x2, y2, x3, y3) は3つの角の座標（6つの引数）を指定します。

  • 順序を入れ替えても同じ三角形が描かれます。
  • 直角三角形や非対称な三角形も自由に構築可能です。
triangle(
  200, 100, // 頂点1 (上)
  120, 280, // 頂点2 (左下)
  280, 280 // 頂点3 (右下)
);

Point & StrokeWeight

点を打つ point() と線の太さ strokeWeight()

point(x, y) は単一のピクセルに点を描画します。そのまでは小さすぎるため、通常は strokeWeight(pixels) と組み合わせて太さを調整します。

挿絵：点は strokeWeight() で大きさが変わる

strokeWeight(5);
point(200, 200);

strokeWeight(1);

State Retention

ステートの罠：strokeWeight の引き継ぎ

p5.jsは描画の状態（ステート）を保持し続けます。そのため、一度 strokeWeight(5) を呼ぶと、次に変更するまで後続のすべての図形（四角形や線など）の輪郭まで太くなってしまいます。

鉄則： 特別な太さや色に変更した後は、必ず元の設定（例: strokeWeight(1)）に戻す記述を入れましょう。

バグを防ぐポイント

ループ内や特殊な描画ブロックの前後で、ペンの太さや塗りの状態がどのように引き継がれているかを意識することが重要です。

Summary & Practice

様々な図形を組み合わせて描いてみよう

長方形だけでなく、円、直線、三角形、点を自由に配置できるようになりました。
数値を少しずつ変えてプレビューを確認し、自分だけの表現を探求してみましょう。

今回の重要ポイント

  • ellipse() : 中心座標と直径を指定して円や楕円を描く
  • line() : 2点間の座標を結ぶ
  • triangle() : 3つの頂点座標を指定する
  • strokeWeight() : 点や線の太さを変更し、必ずリセットする
