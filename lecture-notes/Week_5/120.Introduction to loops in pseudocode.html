Concept of Iteration

反復処理（Iteration）の必要性

サーモスタットの温度制御を、フローチャート（左）と擬似コード（右）で見比べてみましょう。同じ処理を2つの表現で確認すると、反復の意味が掴みやすくなります。

Flowchart

Pseudocode

t ← 18
T ← 20

if t < T then
    t ← t + 0.5
end if

/* 1回では足りない場合、どうする？ */

1回だけの if-then では目標温度に届かないことがあります。だからこそ、目標に到達するまで処理を繰り返す（loop）という発想が必要です。

Iteration in Pseudocode
For Loops

Fixed Iteration

回数が決まっている反復：for ループ

for ループは、特定の回数だけ処理を繰り返すための制御構造です。
変数（例：i）を初期化し、目標値に達するまで処理を繰り返します。

x ← 1
for 2 ≤ i ≤ 10 do
    x ← x + i
end for
x ← 2
for 0 ≤ i ≤ 2 do
    x ← x × 2
end for

While Loops

Conditional Iteration

条件を満たす限り反復：while ループ

while ループは、特定の条件が「真（True）」である限り処理を継続します。
ループ本体（body）の中で、条件に関わる変数を手動で更新する必要があります。

右の擬似コードは、先ほどの for ループ（和を求める）と全く同じ結果を出力します。

x ← 1
y ← 0
while x < 11 do
    y ← x + y
    x ← x + 1
end while

Problem Solving

Applied Problem

方程式 x2 = n は整数解を持つか？

問題の定義

入力として整数 n が与えられたとき、二乗して n になるような整数 x が存在するかを判定します。
戻り値は TRUE または FALSE です。

解法アプローチ

平方根を直接計算するのではなく、整数 i を 1 から順番に二乗し、n と等しくなるものがあるかを探す「反復的」なアプローチを取ります。

Iteration in Pseudocode
For Loop Approach

Solution 1

for ループによる解法

i を 1 から n まで順番に調べます。

欠点：たとえ i2 が n を大きく超えても、ループは律儀に n 回目まで反復し続けてしまいます。

function IsXInteger(n)
    y ← FALSE
    for 1 ≤ i ≤ n do
        if i2 = n then
            y ← TRUE
        end if
    end for
    return y
end function
Iteration in Pseudocode
While Loop Approach

Solution 2 (Optimised)

while ループによる最適化

i2 ≤ n である限りループを続けます。

i2 が n を超えた時点で自動的にループが終了するため、不必要な計算を省くことができます。

function IsXInteger(n)
    y ← FALSE
    i ← 1
    while i2 ≤ n then
        if i2 = n then
            y ← TRUE
        end if
        i ← i + 1
    end while
    return y
end function

Loop Control Flow

Advanced Control

ループの制御：break と continue

Break（ブレイク）

条件を満たした瞬間に、ループ全体を完全に停止して抜け出します。

x ← 1
y ← 0
while x < 11 do
    y ← x + y
    x ← x + 1
    break
end while

Continue（コンティニュー）

ループの残りの処理をスキップし、次の反復（イテレーション）へ即座にジャンプします。

x ← 2
for 0 ≤ i ≤ 2 do
    x ← x × 2
    continue
end for
