Concept of Functions

Input & Output

関数（Functions）の概念
「入力から出力を導くメカニズム」

擬似コードは、実際のプログラミング言語にある関数（Functions）などの機能を再現します。

関数とは、計算機科学や数学における非常に普遍的な概念です。特定の入力（Input）を受け取り、計算を行い、出力（Output）を返します。

Anatomy of a Function

擬似コードにおける関数の定義

関数には、変数のときと同じように「どのような問いを解決するか」を示す名前を付けます。

  • function キーワードで開始する。
  • 名前の後のカッコ ( ) の中に入力を定義する。
  • 関数の終わりには end function を置く。
function EVEN(n)
  // ここに body（処理内容）を書く
end function

Termination

結果の返却と終了（Return）

出力（Output）の生成

関数内部の処理（Body）が完了し、入力に対する答えが見つかったとき、関数は出力を生成します。

Return キーワード

RETURN というキーワードを用いることで、計算結果を関数の外へ返し、同時にその関数の処理を即座に終了（Terminate）させます。

Practical Example

Even or Odd

実践：偶数・奇数の判定関数

正の整数を受け取り、それが偶数なら TRUE、奇数なら FALSE を返す関数 EVEN の例です。

mod 2（2で割った余り）を利用し、if-then構文の条件分岐によってそれぞれ異なる真偽値を出力して関数を終了します。

function EVEN(n)
  if n mod 2 = 0
    return TRUE
  else
    return FALSE
  end if
end function

Encoding Agnostic

データ表現への非依存性

擬似コードは、入力された数値がどのようにエンコード（表現）されているかに依存しません。

  • 人間が使う 10進数 (Decimal form)
  • コンピュータが使う 2進数のビット列 (Bit string)

どのような基数（Base）で記述されていても、モジュロ演算（mod）はアルゴリズムを学習する上での基本的な数学的ツールキットとして機能します。
