Previous Constraints

おさらい：前回の誕生日問題

リソースと条件

  • おもちゃ： 48個
  • お菓子： 42個
  • 条件： 全てを余らせず、各ゲストに均等に配る

導き出された解

ユークリッドの互除法により、最大公約数（GCD）を算出しました。

GCD(48, 42) = 6 Guests
Previous Problem
New Constraints

Jealousy Prevention

新たな制約：「兄弟の存在」

最大6人のゲストを招待できることが分かりましたが、新たな問題が発生しました。

一部のゲストには「兄弟（Siblings）」がいます。兄弟間の嫉妬を防ぐため、招待したゲストの兄弟にも、ゲストと全く同じ数のおもちゃとお菓子を配らなければなりません。

New Constraints
The Data

Input Data

提供されたゲストリスト

主役（あなたの兄弟）から、招待候補となる6人のリストが渡されました。それぞれに兄弟が何人いるかが記されています。

ゲストを1人招待すると、その兄弟も含めた人数分の「配分枠」が消費されることになります。

Guest List & Siblings

  • Guest 1: 0 siblings (Total: 1)
  • Guest 2: 2 siblings (Total: 3)
  • Guest 3: 1 sibling (Total: 2)
  • Guest 4: 0 siblings (Total: 1)
  • Guest 5: 1 sibling (Total: 2)
  • Guest 6: 1 sibling (Total: 2)
Input Data
The Core Question

Optimization Problem

問い：最大何人の「ゲスト」を招待できるか？

ゲストとその兄弟を合わせた合計人数が「ちょうど6人」になり、かつ「招待するゲストの数」を最大化するには、どのゲストを選べばよいでしょうか？

これは一種の最適化問題（組み合わせ問題）です。条件を満たす組み合わせを手作業で探してみましょう。

Advanced Challenge

発展演習：アルゴリズムの一般化

任意の変数への拡張

時間に余裕がある場合は、この問題を一般化して考えてみましょう。
おもちゃが X 個、お菓子が Y 個あり、そのGCDを N 人とします。

思考のポイント

  • N 人のゲストリストがあり、各ゲストが任意の数の兄弟を持つ場合、この問題には常に解が存在するでしょうか？
  • この解を導き出す手順を、擬似コード（Pseudocode）を使って記述できるか挑戦してください。

Algorithmic Modeling

擬似コードによる表現のヒント

アルゴリズムを設計する際は、まずデータをどのように保持するかを考えます。

ゲストのリストは、配列（Array）や変数を使って表現できます。例えば、各ゲストの「本人＋兄弟の合計数」を保持するリストを作成し、合計が N になる組み合わせを探索するループを構想します。
