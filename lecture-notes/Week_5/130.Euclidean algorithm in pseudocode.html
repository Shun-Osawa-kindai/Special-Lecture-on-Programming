ユークリッド互除法の関数実装

フローチャートで描かれたユークリッドの互除法を、2つの異なるアプローチ（ForループとWhileループ）を用いて、擬似コードの関数（Function）として書き起こします。

Algorithm Solutions
For Loop Approach

Implementation 1

Forループによる実装

a + b 回という十分に大きな反復回数を設定し、差分処理を行います。

a = b になった瞬間に break でループから脱出し、結果を返します。

function GreatestCommonDivisor(a, b)
    for 0 ≤ i ≤ a + b do
        if a = b then
            break
        end if
        if a > b then
            a ← a − b
        else
            b ← b − a
        end if
    end for
    return a
end function

While Loop Approach

Implementation 2

Whileループによる実装

a ≠ b である限り反復を続ける構造です。

break や不要な上限設定がなくなり、関数全体がよりシンプルで洗練された形になります。

function GreatestCommonDivisor(a, b)
    while a ≠ b do
        if a > b then
            a ← a − b
        else
            b ← b − a
        end if
    end while
    return a
end function

Intuition & Experience

反復処理の特性と直感の醸成

Whileループの性質

Forループのように単に1ずつ増加させるだけでなく、毎回のイテレーションで意味のある変数の更新（代入）が行われます。終了回数が不明なタスクに適しています。

経験の重要性

「どのループをいつ使うべきか」というツール選択の直感は、使用すればするほど自然に身につきます。今後の学習において極めて有用な基盤となります。

Lack of Universality

擬似コードの記法における多様性

擬似コードは特定のプログラミング言語に依存しませんが、教科書や文献によって記法のルール（Conventions）が異なるという問題があります。

  • 本モジュールの記法と他文献の記法の違いに気づくこと。
  • 両方を理解できれば、世の中のほぼ全ての擬似コードを解読できます。
  • 英語ベースで記述されること自体も、完全な普遍性を制限しています。
