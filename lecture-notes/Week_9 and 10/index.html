Special Lecture on Programming

第9・10回 Data persistence, databases, and state changes

授業形式：演習を含む講義（2回分を1つの資料群として公開）

授業計画の内容（第9回・第10回）

Data persistence； arrays versus databases； data models； program state の表現； State changes； data creation and update； history； application と database の接続

このページの使い方

  • この index.html から、同一フォルダ内の教材ファイルへ直接移動できます。
  • 学生向けの入口は 00_Student_Start.html です。まずここから開始してください。
  • 既存ファイル同士のリンクはそのまま維持し、入口だけを一元化しています。
