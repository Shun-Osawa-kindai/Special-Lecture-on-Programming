Binary & Memory

Bits and Bytes

なぜ数値を 0 から 255 までで指定するのか？

コンピュータのメモリは小さなスイッチ（ビット）の集合体です。1バイト（8ビット）の組み合わせ総数は 2の8乗 ＝ 256通り です。

コンピュータは 0 から数え始めるため、表現できる最大値は 255 となります。
