The Screen & Pixels

Pixels Grid

画面はピクセルのグリッド

コンピュータの画面は、無数の小さな点の集合体「ピクセル」で構成されています。p5.jsでは、このピクセルグリッド上に図形を描画します。

Creating Canvas

Canvas Setup

キャンバスの作成：createCanvas()

描画領域を作るには createCanvas(width, height) 命令を使います。

  • 第1引数： キャンバスの幅（Width）
  • 第2引数： キャンバスの高さ（Height）
  • 命令の末尾には必ずセミコロン（;）をつけます。
createCanvas(500, 500);

Origin Point

Cartesian Coordinates

原点 (0, 0) は「左上の角」

学校の数学では原点 (0, 0) は通常「中央」や「左下」にありますが、コンピュータグラフィックスでは左上の角が (0, 0) になります。

Coordinates & Shapes Slide 3 / 8
Axes Direction

Axis Movement

X軸は右へ、Y軸は下へ進む

座標の増える向き

  • X軸（横方向）： 右に進むほど値が大きくなる
  • Y軸（縦方向）： 下に進むほど値が大きくなる

p5.jsはこの座標ルールで描画されるため、意図した位置に図形を置くには「どちらがプラスか」を最初に覚えるのがコツです。

Rectangle Command

Rectangle Drawing

長方形を描く：rect(x, y, width, height)

rect() 命令には4つの引数（数値）を指定します。

  • x, y： 長方形の「左上の角」の位置
  • width： 長方形の横幅
  • height： 長方形の高さ
rect(100, 100, 200, 200);

Layout Calculation

Positioning Shapes

複数の図形を並べるための座標計算

1つ目の四角形（rect(100, 100, 100, 100);）の右隣に2つ目を並べるには、X座標の計算が必要です。

2つ目のX座標の求め方

最初のX(100) ＋ 幅(100) ＋ 隙間(50) ＝ 250

createCanvas(500, 500);
rect(100, 100, 100, 100); // 1つ目
rect(250, 100, 100, 100); // 2つ目（隣に配置）
