Key Codes

Key Detection

矢印キーの識別：key vs keyCode

文字変数：key の限界

通常の文字キー（'A', 'W' など）は key で判定できますが、矢印キーのような特殊キーを押すと % や ' といった文字化けのような記号が渡されてしまいます。

数値変数：keyCode が確実

キーボードの物理キーごとに割り振られた固有の整数値（Key Code）を使用することで、誤作動なく正確に矢印キーを検知できます。

← 左矢印キー： 37
→ 右矢印キー： 39

State Transition Safety

Logical Trap

キー入力時の状態遷移は newState で安全に更新する

キー入力イベントの中で、判定対象の gameState を直接書き換えると、1回の入力で条件が連鎖し、意図しない状態へ進むことがあります。

解決策： 一時変数 newState に変更先を保持し、最後にまとめて gameState へ反映します。

function keyPressed() {
  var newState = gameState;
  if (gameState == 0) {
    newState = 1; // スタート
  } else if (gameState == 2) {
    newState = 0; // リトライ準備
  }
  gameState = newState; // 最後に反映
}

⚠️ 移植の注意点：

if (isLeft) {

  drawLeftWalkingPose();

} else {
  // キー操作なし：正面立ちポーズ

draw() ループでの連続的な座標更新

ポーズの切り替えに加え、フラグが true の間は毎フレームキャラクターのX座標（gameChar_x）を加算・減算します。

Timer Mechanics

制限時間を作る：カウントダウンタイマーの導入

キャラクター移動が完成したら、ゲーム性を高めるために制限時間（countDown）を導入できます。時間内に目標へ到達させる課題に発展させやすくなります。

  • 初期化： 開始時に countDown = 300; などを設定
  • 減算： プレイ中（gameState == 1）のみ毎フレーム減らす
var countDown = 300;

// プレイ中の draw() 内
if (gameState == 1) {
  countDown = countDown - 1;
}
