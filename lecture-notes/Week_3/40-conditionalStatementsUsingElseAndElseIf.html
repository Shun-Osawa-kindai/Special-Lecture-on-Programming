Else Keyword

Else Keyword

条件が満たされない場合の処理
「else」の活用

これまで学んだ if 文では「条件が真（true）のとき」のアクションを指定していましたが、else キーワードを使うことで「それ以外のとき（偽のとき）」に行うアクションを簡潔に記述できます。

if ( name == "Neumann" ) {
  console.log("Hello Neumann");
} else {
  console.log("Hey, you're not Neumann!");
}

Lab Safety Rule

Lab Safety Rule

実験室ルールでの else の適用

実験室への入室判定でも、else を使えば「条件を満たした場合」と「それ以外」を明確に書き分けられます。ここでは「保護メガネを着用しているか」を例にします。

if (wearingGoggles) {
  canEnterLab = true; // 入室許可
}
else {
  canEnterLab = false; // 未着用なら入室不可
}

Else If Chaining

Else If Chaining

複数の条件をチェーンさせる else if

2つ以上の複数の条件を順番に判定したいときは else if を使って条件を連鎖させます。上から順にテストされ、最初に一致したブロックの処理だけが実行されます。

if (name == "Neumann") {
  console.log("Hello Neumann");
}
else if (name == "Neumanne") {
  console.log("Hello Neumanne");
}
else {
  console.log("I don't know you");
}

Minimal Example

Practical Mini Example

最小の else if 例：温度で表示を切り替える

if で最初の条件、else if で次の条件、最後に else で「どれにも当てはまらない場合」を処理します。まずはこの3段構成を確実に使えるようにしましょう。

if (temperature >= 30) {
  message = "暑いので換気しよう";
} else if (temperature >= 20) {
  message = "作業しやすい温度です";
} else {
  message = "寒いので上着を着よう";
}

Logic Pitfall 01

Logic Pitfall

落とし穴①：条件の順番と排他性

else if チェーンでは、上から順番に判定が行われ、一度条件が一致するとそこで処理が打ち切られます。そのため、条件を書く順番を間違えると、後続の条件が一生実行されないバグ（論理エラー）が発生します。

注意点

限定的な条件を下に書き、広すぎる条件（例: x > 10）を上に書いてしまうと、その下の細かい条件（例: x > 100）が永遠にスキップされてしまいます。

Logic Pitfall 02

Logic Pitfall

落とし穴②：独立した条件は別々の if にする

「名前がNeumannか」と「役割がティーチャーか」のように、同時に判定して両方の処理を実行させたい場合、else if で繋いでしまうと最初の条件で止まってしまいます。

鉄則： 全く独立した2つの結果を出力したいときは、チェーンさせずに別々の if 文として独立させましょう。

if (name == "Neumann") {
  console.log("Hello Neumann");
}

if (role == "teacher") {
  console.log("You are a teacher");
}
