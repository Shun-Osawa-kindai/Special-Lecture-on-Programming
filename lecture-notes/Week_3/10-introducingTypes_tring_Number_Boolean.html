Hardware View

Boolean in Engineering

工学的アプローチ：Boolean = 回路の ON/OFF

  • ON/OFF: 電流が流れる（1 / true）、流れない（0 / false）
  • AND（直列）: 両方のスイッチが ON のときだけ点灯
  • OR（並列）: どちらか片方が ON なら点灯
  • NOT（反転）: 入力の反対状態を出力
  • MOSFET: このスイッチ動作を半導体で実現し、CPU/メモリへ発展

String Variables

テキストデータを扱う String（文字列）型

文字、単語、文章、あるいは長文まで、テキストデータは文字列（String）として保存できます。シングルクォーテーション（'）またはダブルクォーテーション（"）で囲んで作成します。コード内で一貫性を持たせるのが美しい書き方のコツです。

var greeting = "Hello";
var target = 'World';

Concatenation

String Concatenation

プラス演算子（+）による文字列の結合

文字列同士は、算術の足し算と同じ + 演算子を使って結合（Concatenation）することができます。

ただし、数値と文字列の間で + を使うとJavaScriptが自動的に型変換（解釈）を行うため、意図しない挙動（バグ）に注意が必要です。

var str1 = "Hello";
var str2 = "World";
var combined = str1 + " " + str2;

Type Safety

Type Checking & Casting

typeof で型を確認し、安全にキャストする

入力値や外部データは、見た目だけでは型が分かりません。まず typeof で型を確認してから、必要に応じて変換（キャスト）するとバグを減らせます。

  • 数値化: Number(value)
  • 文字列化: String(value)
  • 判定前に「型が想定通りか」をチェックする習慣が大切
var scoreText = "120";
if (typeof scoreText == "string") {
  var score = Number(scoreText);
  console.log(score + 10); // 130
}

// 文字列のままだと "12010" になる点に注意
