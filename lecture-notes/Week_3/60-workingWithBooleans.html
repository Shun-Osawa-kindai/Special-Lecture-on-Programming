Boolean Variable

Step 2：Boolean変数で壁のON/OFFを作る

バウンスボールの右壁反射を制御するために、新しいBoolean変数を作成します。
名前を rightWallEnabled とし、初期値として false を代入して「右壁は反射しない」状態からスタートします。

var rightWallEnabled = false;  // 初期状態：右壁OFF

Conditional Coloring

状態に応じて色を切り替える (if / else)

右壁の有効・無効に応じて、描画される壁ラインの色を動的に変更します。Booleanは2つの状態（真・偽）を持つため、if / else 分岐と相性が抜群です。

if (rightWallEnabled) {
    stroke(70, 200, 120);   // ON：反射あり
} else {
    stroke(200, 200, 200);  // OFF：反射なし
}

User Interaction

mousePressed() による状態の切り替え

ユーザーがマウスをクリックした瞬間に実行される mousePressed() 関数を定義し、クリックのたびに rightWallEnabled の値を書き換えます。

function mousePressed() {
    if (rightWallEnabled == true) {
        rightWallEnabled = false;
    } else {
        rightWallEnabled = true;
    }
}

Code Refinement

否定演算子（!）でコードをスマートに

冗長な条件式を短縮し、エレガントに表現するための2つの短縮テクニックです。

  • if (rightWallEnabled) : == true は不要
  • rightWallEnabled = !rightWallEnabled; : 状態を瞬時に反転（トグル）
function mousePressed() {
    // 現在の反対の状態を代入して反転
    rightWallEnabled = !rightWallEnabled;
}
