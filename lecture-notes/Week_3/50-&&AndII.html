OR Operator

OR Operator (||)

どちらか一方が満たされれば良い OR (||)

2つの縦棒記号（パイプ記号: ||）を並べると OR 演算子になります。条件A または条件B のどちらか一方が真（true）であれば、アクションが実行されます。

  • 注意点： role == "teacher" || "student" のように省略して書くことはできません。必ず両側に完全な比較式を書く必要があります。
if (role == "teacher" || role == "student") {
  console.log("Hi, welcome!");
}

Practical OR

Practical OR Example

一般例：どちらかを満たせば警告する

OR（||）は「AまたはBのどちらかが危険なら対応する」のような運用ルールでよく使います。たとえば温度か湿度のどちらかが閾値を超えたら、換気アラートを出す設計です。

if (temperature > 35 || humidity > 80) {
  console.log("換気アラートを出す");
}

AND Operator

AND Operator (&&)

両方の条件が同時に真でなければならない AND (&&)

2つのアンパサンド記号（&&）を並べると AND 演算子になります。条件A と条件B の両方が同時に真（true）であるときのみアクションが実行されます。どちらか片方でも偽であれば実行されません。

if (name == "Neumann" && role == "teacher") {
  console.log("Hi teacher Neumann");
}

Logic Pitfall

Logic Pitfall

AND演算子の落とし穴：不可能な条件の記述

role == "teacher" && role == "student" のように、同一の変数に対して同時に2つの異なる値を求めるような条件を書くと、永遠に真になりません（変数は同時に1つの値しか持てないため）。

原則： AND演算子を使うときは、通常異なる変数を組み合わせてチェックします。

チェックのポイント

「この条件とこの条件が両方とも同時に成立しうるか？」を常に意識して設計しましょう。
