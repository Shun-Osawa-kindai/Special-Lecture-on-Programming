Part 2Bで作成した collectable 変数とオブジェクト定義を、Part 3のスケッチの setup() 内へコピーします。

Visibility Control

isFound による「消える」描画制御

アイテムを消すために描画命令を削除する必要はありません。

draw() 内のアイテム描画コード全体を if (collectable.isFound == false) で包むだけで、拾われた（true になった）瞬間に自動的に描画がスキップされ、画面から綺麗に消え去ります。

条件付き描画ブロック
if (collectable.isFound == false) {
  fill(255, 215, 0);
  ellipse(collectable.x_pos, collectable.y_pos, 20, 20);
}

Style Reset

描画スタイルの汚染を防ぐリセット処理

⚠️ 発生するトラブル

コイン等のアイテム描画内で noStroke() や特殊な輪郭色・太さを設定したままにしておくと、その直後に描画されるキャラクターの輪郭線が消えたり色化けする事故（ステート汚染）が起きます。

💡 解決策：直前に明示リセット

キャラクターを描くブロックの直前で、ペンの輪郭を元の規定値（黒色・太さ1）に戻します。

stroke(0);        strokeWeight(1); Collectable Interaction

Distance Measurement

dist() 関数による2点間の距離判定

キャラクターがアイテムに触れたかを判定するには、2点間の直線距離を測る dist(x1, y1, x2, y2) を使います。

  • 点1： キャラクター座標（gameChar_x, gameChar_y）
  • 点2： アイテム座標（collectable.x_pos, collectable.y_pos）
  • 距離が 20px 未満なら「拾った範囲」とみなします。

Pickup Code

接触時に isFound を true に更新する

draw() 内に条件分岐を追加します。

dist() の計算結果が 20 未満になった瞬間に collectable.isFound = true; を代入します。

※if 文の条件カッコの末尾にはセミコロン（;）を絶対につけないよう注意しましょう。

draw() 内の接触判定ロジック
if (dist(
    gameChar_x, gameChar_y,
    collectable.x_pos, collectable.y_pos
  ) < 20) {
  isFound = true;
}
