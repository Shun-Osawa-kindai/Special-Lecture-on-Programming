User Interaction

Mouse Events

マウスクリックに反応させる：mousePressed()

ユーザーがマウスのボタンを押した瞬間に特定の処理を実行したい場合、mousePressed() という専用の関数を定義します。

  • function mousePressed() の形式で記述します。
  • P が大文字（キャメルケース）であることに注意します。
  • クリックされたタイミングで、波カッコ {} 内の処理が1回呼び出されます。
クリックで赤色に変更
function mousePressed() {
  fill(255, 0, 0); // 塗りつぶしを赤に
}

Important Concept

State & Drawing Loop

なぜクリックしても色が変わらないのか？

draw() 内で毎回 fill(255) を実行している場合

クリック時に赤色へ変更されても、直後のフレームで draw() 内の白色で上書きされてしまい、変化が目に見えません。

function draw() {
  fill(255); // 毎フレーム白に上書き
  ellipse(mouseX, mouseY, 50, 50);
}

setup() で初期色を指定する場合

初期状態の白色を setup() に移動すると、イベントで変更された赤色が保持されるようになります。

function setup() {
  createCanvas(600, 600);
  fill(255); // 初期色をセット
}
描画状態の維持：p5.jsでは、新しい指定があるまで前回の fill() や stroke() の設定が維持されます。

Keyboard Interaction

Keyboard Events

キー入力に反応させる：keyPressed()

キーボードのいずれかのキーが押された瞬間に反応させたい場合は、keyPressed() 関数を使用します。

  • キーが押されると自動的に実行されます。
  • 黄色（RGB: 255, 255, 0）など、異なる色の切り替えを追加できます。
  • マウスクリックと組み合わせることで、多様な操作を実現できます。
キー押下で黄色に変更
function keyPressed() {
  fill(255, 255, 0); // 塗りつぶしを黄色に
}

Naming Convention

Camel Case

関数の命名規則：キャメルケース (camelCase)

p5.jsの組込み関数や変数の多くは、大文字と小文字を組み合わせた「キャメルケース」というルールで命名されています。

キャメルケースの約束事

  • 小文字で始まり、2つ目の単語の先頭を大文字にします。
  • 単語と単語の間にスペースは入れません。
  • ラクダ（Camel）のこぶのように途中で盛り上がる形状が由来です。

具体例

× mousepressed  （反応しない）

× MousePressed  （先頭が大文字）

○ mousePressed  （正しい記法）

○ keyPressed   （正しい記法）

Interactive Creation

マウス移動による追従に加え、クリックやキー入力によって色やサイズが変化する仕組みを作ることができました。

  • キー入力でキャンバスの背景色を初期化できるようにしてみる
