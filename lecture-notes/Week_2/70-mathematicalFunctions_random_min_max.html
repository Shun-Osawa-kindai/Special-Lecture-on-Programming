Math Functions

Drawing vs Returning Values

描画関数から
「数値を返す数学関数」へ

これまでの関数（描画・設定）

ellipse() や fill() などは、画面に直接図形を描画したり、描画状態を変更するための命令でした。

これからの関数（数学関数）

random(), min(), max() などは、画面を一切変化させず、「計算された数値を結果として返す（Return）」関数です。

返された数値をそのまま画面に表示したり確認するには、console.log() を利用します。

Random Function

Generating Random Values

ランダムな数値を生成する：random()

引数の指定方法と生成される範囲

  • random() ➔ 0 以上 1 未満の小数を返す
  • random(250) ➔ 0 以上 250 未満の小数を返す
  • random(50, 250) ➔ 50 以上 250 未満の小数を返す

実行されるたびに毎回異なる数値が得られます。図形の幅や高さ、位置、色などに与えることで不規則で表現豊かなグラフィックが作れます。

ランダムなサイズの楕円
function draw() {
  background(220);
  // 毎フレーム、幅と高さが別々にランダム変化
  ellipse(200, 200, random(50, 250), random(50, 250));
}

Random & Variables

Storing Random Results

変数に代入して乱数の結果を保持する

random() を関数引数のなかで直接2回呼び出すと、幅と高さに別の乱数が与えられて歪んだ楕円になります。幅と高さを等しく揃えて「整った正円」にするには、一度計算結果を変数に保存します。

一度変数に代入するメリット

  • var r = random(50, 250); で乱数値を確定
  • ellipse(200, 200, r, r); と指定すれば、同じ数値 r が適用されて綺麗な正円を保てる
ランダムなサイズの正円
function draw() {
  background(220);
  var r = random(50, 250); // 乱数を変数rに保持
  ellipse(200, 200, r, r); // 同じrを使う
}

Min Function

Upper Limit Restriction

上限を制限する：min() 関数

min(a, b) は与えられた2つの数値のうち「小さい方（最小値）」を返します。これを利用すると、値が一定以上大きくならないように「上限（ストッパー）」を設けることができます。

① カーソル移動の範囲制限

var x = min(mouseX, 250);
カーソルが250pxを超えて右へ移動しても、250と比べられて「常に小さい方の250」が選択されるため、画面中央より右へ進まなくなります。

② アニメーションの停止（ストップ）

x = min(x + 1, 250);
フレームごとに1ずつ増加しますが、250に達した瞬間に加算（251）よりも250が選ばれるようになり、ボールが自動的に停止します。

Max & Advanced Math

Lower Limit & Useful Functions

下限を制限する max() とその他の便利な関数

下限（ストッパー）を作る max(a, b)

max(a, b) は与えられた数値のうち「大きい方」を返します。
x = max(x - 1, 250); のように記述すると、右から左へ移動するアニメーションが 250px より小さくならず綺麗に停止します。

今後役立つ関連数学関数

  • constrain(val, min, max): 値を指定範囲内に強制クランプする
  • map(val, inMin, inMax, outMin, max): 数値の範囲を別の範囲へ変換する
  • floor() / round(): 小数点の切り捨てや四捨五入を行う

Self-Directed Learning

Teach It To Yourself

自ら学ぶ力（独学のすすめ）

優れたプログラマーになるためには、自立した学習者であることが重要です。プログラミング言語や技術は頻繁に変化するため、新しい構文やテクニックをご自身で学ぶスキルが求められます。

このコースでは、あえていくつかの領域を未解説のまま残しています。公式の p5.jsリファレンスガイド やオンラインリソースを活用して、自分でコードを学ぶ練習をしましょう。

今後に向けて自習すべき3つの領域

  • 1. 追加イベント: keyReleased(), mouseReleased(), mouseMoved(), mouseDragged(), key, keyCode (Case 303等)
  • 2. 演算子の短縮形: +=, -=, /=, *=
  • 3. 数学関数: random(), min() / max(), map(), constrain()
