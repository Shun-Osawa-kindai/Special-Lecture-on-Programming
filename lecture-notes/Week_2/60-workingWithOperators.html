Dynamic Variables

Static Values to Motion

静的な値から
「プログラム実行中の値の更新」へ

これまでの変数（静的データ）

これまでは、最初に初期化した数値をそのまま保持し、図形の固定位置として使ってきました。値を手動で書き換えない限り、グラフィックは静止したままです。

これからの変数（動的データ）

JavaScriptは優れた「計算機」です。算術演算子（+, -, *, /）を使い、プログラムの実行中に変数の値を刻々と書き換えることで、画面に命を吹き込みます。

Value Persistence

Arithmetic vs Assignment

算術演算だけでは「変数の値」は変わらない

誤解しやすい書き方
var yPos = 120;

ellipse(100, yPos, 20, 20);
ellipse(100, yPos + 20, 20, 20); // 描画位置だけ足し算
ellipse(100, yPos + 40, 20, 20);

console.log(yPos); // 結果は 120 のまま

引数内での計算（一瞬の計算）

ellipse(100, yPos + 20, ...) のように関数の引数の中で足し算をしても、その場での表示位置が変わるだけで、メモリ内の yPos の値自体は一切更新されません。

代入演算子（=）の必要性

変数の値を実際に上書きして更新するためには、単なるプラス記号ではなく代入演算子（=）を使う必要があります。

Assignment Concept

Self-Referential Assignment

変数を更新する基本式：yPos = yPos + 20

一見すると数学の方程式としておかしく見えますが、プログラミングでは「右辺の計算結果で、左辺の変数を上書き更新する」という意味になります。

「新しい値 ＝ 現在の値 ＋ 加算量」

  • 元々の yPos が 120 だった場合：
    右辺 120 + 20 ➔ 140 を計算し、yPos に新しく代入。
  • 次にこの行が実行されると：
    右辺 140 + 20 ➔ 160 が新しい yPos になる。
代入による変数の推移
var yPos = 120;

ellipse(100, yPos, 20, 20); // Y: 120
yPos = yPos + 20; // 値を 140 に上書き

ellipse(100, yPos, 20, 20); // Y: 140
yPos = yPos + 20; // 値を 160 に上書き

ellipse(100, yPos, 20, 20); // Y: 160

Loop & Animation

draw() Repetition

draw() ループでアニメーションを生み出す

draw() 関数は毎秒約60回リピート実行されます。ループの中に yPos = yPos + 1; を置くことで、時間が経過するごとにボールがスムーズに下へと動きます。

background() で残像をクリア

draw() の冒頭で background(220); を呼び出すと、毎フレーム前回の位置を塗りつぶしてリセットするため、「ボールが移動している」綺麗なアニメーションになります。

滑らかなボールの降下
var yPos = 0;

function draw() {
  background(220); // 毎フレーム残像を消す
  ellipse(200, yPos, 30, 30);

  yPos = yPos + 2; // 毎フレーム 2px ずつ更新
}

Motion Variation

Speed & Direction

加算量と軸の工夫による動きのバリエーション

① 斜め移動

xPos と yPos の両方を同時に加算更新することで、ボールが斜めに進みます。

xPos = xPos + 2;
yPos = yPos + 2;

② 速度の調整

加算する数値を大きくすると高速移動し、数値を小さく（0.5など）すると低速になります。

8;

③ 逆方向への移動

プラス（加算）の代わりにマイナス（引き算）を使うと、オブジェクトが上や左へ戻る動きを作れます。

3;

Summary & Challenge

Endless Possibilities

位置以外の属性もアニメーションさせてみよう

変数を時間とともに書き換えるテクニック（var = var + val）は、位置（XY座標）の移動だけに留まりません。

アレンジ・チャレンジ

  • サイズの拡大・縮小：radius = radius + 1; で円が巨大化するアニメーション
  • 色の変化：redVal = redVal + 2; で徐々に赤みが強くなるグラデーション変化
  • 方向の反転：画面端に達した時に加算量をマイナスに切り替える処理

「変数を変化させる。それが、すべてのインタラクティブの原点」
