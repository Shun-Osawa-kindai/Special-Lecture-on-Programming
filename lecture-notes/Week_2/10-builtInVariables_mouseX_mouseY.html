Concept of Variables

Dynamic Values

固定された数値から、
「変数」の世界へ

これまでは、図形を描くときに 200 や 400 といった「固定値（絶対値）」を記述してきました。

静止画を描くにはこれで十分でしたが、アニメーションやユーザー操作（インタラクション）を実現するには、プログラム実行中に刻々と変化する数値を受け取る「プレースホルダー（器）」が必要になります。

Mouse Interaction

System Variables

マウス座標と運動：mouseX / mouseY

p5.jsには、現在のマウスカーソルの位置を自動で保持・更新してくれる特別なシステム変数が用意されています。

  • mouseX：キャンバス上の横方向（X座標）
  • mouseY：キャンバス上の縦方向（Y座標）

※先頭が小文字、2語目の頭が大文字のキャメルケース記法です。

マウス追従の例

ellipse(mouseX, mouseY, 50, 50);

Variables Under the Hood

変数の正体：メモリに情報を保存する「器」

変数（Variable）は、コンピュータのメモリ領域に名前をつけて小さな情報を保存しておく「プレースホルダー」です。

プログラムの中で mouseX という名前を呼ぶと、p5.jsはその瞬間に測定された実際の数値（例: 342）に置き換えて命令を実行します。

Computer Memory
[ mouseX ] ➔ 285
[ mouseY ] ➔ 140

Canvas Dimension Variables

Responsive Dimensions

画面寸法に連動する：width / height

createCanvas(w, h) で設定したキャンバスの横幅と縦幅は、システム変数 width と height に自動格納されます。

直値で 600, 600 と書く代わりに width, height を使うことで、キャンバスサイズを変更しても自動的に追従する柔軟な画面を作れます。

function setup() {
  createCanvas(800, 800);
}

ellipse(400, 400, width, height);
