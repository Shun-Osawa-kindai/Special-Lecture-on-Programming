ロボットをハックする (Hack the Robot)

これまで学んだ描画のテクニックが詰まったプログラムを実際に動かし、自分の手でコードを改造して「ハッキング（実験）」してみましょう。

Hack the Robot Slide 1 / 6
Setup & Run

Getting Started

プロジェクトのダウンロードと実行

プラットフォームから演習用ファイルをダウンロードし、Brackets等のエディタで開いて実行します。

  • 1. 配布ファイルを展開してワークスペースに配置
  • 2. プログラムをライブプレビューで実行
  • 3. 画面に表示されるロボットの姿を確認する
setup() {
  createCanvas(500, 500);
}
Hack the Robot Slide 2 / 6
Basic Experiments

Exploration

まず試すべき3つの実験

1. 数値の変更

座標やサイズの数値を書き換えて、画面上の変化を観察する。

2. コメントアウト

// をつけて特定のコードを無効化し、何が消えるか確認する。

3. コピー＆ペースト

既存のコマンドを複製し、数値をずらしてバリエーションを生み出す。

Hack the Robot Slide 3 / 6
Deliberate Changes

Customization Ideas

意図的なカスタマイズに挑戦する

アンテナの形を変える

四角形や三角形を組み合わせて、ユニークな鼻のデザインに作り替える。

目を改造する

二重の円や特徴的な図形を配置して、ロボットに個性的な目を与える。

カラーリングの変更

fill() のRGB数値を調整し、自分好みのカラーテーマに染める。

Hack the Robot Slide 4 / 6
Hacking Mindset

Learning by Doing

コードを壊すことを恐れない

プログラミングの学習において、コードを書き換えてエラーを出したり画面を崩したりすることは、理解を深めるための大切なプロセスです。

動かなくなったら元に戻せばいいという気楽さを持って、積極的にコードをハック（改造）しましょう。

ハッキングの心得

「コードを読む ➔ 予想して変更する ➔ 結果を観察する」のサイクルを高速で回すことが、最も上達への近道です。
