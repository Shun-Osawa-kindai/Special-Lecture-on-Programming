Game Project Part 1

背景オブジェクトを描画する

キャラクターが走り回るための「世界（背景世界）」を構築します。
配布Zipを展開し、ワークスペースにフォルダを配置してスタートしましょう。

Project Kickoff

Drawing Clouds

雲を描く：複数の楕円の組み合わせ

雲は3つの ellipse（楕円）を重ね合わせてふんわりした形を表現します。

  • 白の指定： 描画の前に必ず fill(255); を実行。
  • オフセット： 中央の円を基準に、左右の円のX座標を対称にずらします。
Drawing Clouds

Tree Trunk Logic

木の幹と地面の接点計算

地面の高さ（例: 432）から木の高さ（例: 150）を引き算し、長方形の描画開始Y座標（282）を算出して配置します。

fill(120, 80, 40);
rect(900, 282, 60, 150);
Tree Trunk Logic

Tree Branches

木の葉：三角形のスタッキング

2つの triangle() を高さをずらして重ね、奥行きのある木を表現します。

fill(0, 155, 0);
triangle(850, 332, 930, 232, 1010, 332);
triangle(850, 282, 930, 182, 1010, 282);
